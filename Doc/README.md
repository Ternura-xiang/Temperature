# Temperature

**基于 STM32L031 的低功耗温湿度计**

一款采用 STM32L031、SHT31 和 HT1621B 的小型温湿度计。使用段码 LCD 显示温湿度，通过 RTC 定时唤醒与 STOP 低功耗模式降低功耗，并支持电池电压监测。

项目采用较为常见的器件与电路方案，硬件结构简单，复刻成本较低，适合作为低功耗 STM32 应用、SHT3x 温湿度传感器及段码 LCD 驱动的参考。

## 项目特点

- **低功耗设计**：使用 STM32L031 的 STOP 模式，结合 RTC WakeUp 定时唤醒。
- **温湿度测量**：采用 SHT31 数字温湿度传感器。
- **段码 LCD 显示**：使用 HT1621B 驱动段码屏，交替显示温度与湿度。
- **电池电压监测**：通过 ADC 内部参考电压通道估算供电电压。
- **低成本硬件**：主要器件可通过立创商城采购，适合个人制作与复刻。

## 硬件设计

整机主要由主控电路、温湿度传感器、段码 LCD 驱动电路及供电电路组成。

### 1. 主控电路

主控采用 STM32L031，负责温湿度数据采集、LCD 显示、电池电压测量及低功耗管理。

![STM32L031 主控电路](https://image.lceda.cn/oshwhub/pullImage/38fb3b3a571a4af89066d1d03529aed9.png)

电路预留了 UART 调试接口，方便开发阶段进行调试。Wake 按键可用于唤醒 MCU，并切换显示项目。

由于温湿度计对时钟精度的要求相对较低，外部晶振并非绝对必要。若不焊接外部晶振，需要根据实际使用的时钟源调整软件配置。

### 2. 段码 LCD 驱动

显示部分采用 HT1621B 驱动段码 LCD。

![HT1621B 显示驱动电路](https://image.lceda.cn/oshwhub/pullImage/49f0b1c9d4184db1bf85ebf6e9f691ca.png)

HT1621B 是专用于 LCD 驱动的控制器，可以减少 MCU 直接驱动显示屏所需的 IO 资源。

本项目选用华轩阳提供的 SSOP-24 封装器件，相较于常见的较大封装，更适合小型化设计。具体封装与焊盘兼容性请以对应器件的数据手册为准。

### 3. 温湿度传感器

温湿度传感器采用 SHT31，按照器件数据手册完成外围电路设计，通过数字接口读取温度和相对湿度。

![SHT31 温湿度传感器电路](https://image.lceda.cn/oshwhub/pullImage/01e3363e98df43f5841192cba3e8de01.png)

SHT31 也属于 SHT3x 系列。若需要替换为 SHT30 等兼容器件，应根据对应型号的数据手册检查测量精度、工作条件、通信配置及软件兼容性。

### 4. 供电设计

项目使用 RC2016 电池供电，整机围绕低功耗运行进行设计。

实际续航不仅取决于 MCU 的休眠电流，也受到 LCD 驱动、传感器测量、唤醒频率及电池自身特性的影响。因此，评估续航时应以整机实测电流为依据，而不是仅参考 MCU 的数据手册参数。

## 软件设计

软件采用主循环完成温湿度采集、数据显示、电池电压监测和低功耗管理。

### 1. 温湿度显示

考虑到环境温湿度通常不会在短时间内发生剧烈变化，程序采用交替显示的方式：

- 一次唤醒读取温湿度，并显示温度。
- 下一次唤醒显示上一次采集的湿度。
- 通过交替显示减少不必要的传感器访问。

RTC WakeUp 定时器配置为每 5 秒唤醒一次 MCU。

### 2. 电池电压监测

程序每经过 120 次休眠周期，通过 ADC 的内部参考电压通道测量供电电压。

在已知内部参考电压校准值的前提下，可根据 ADC 转换结果估算 MCU 的供电电压，避免额外增加电池电压采样电路。

核心计算思路如下：

```c
vdda = (uint32_t)(
    ((uint64_t)VREFINT_CAL_VREF_MV * cal + pwr_raw / 2U)
    / pwr_raw
);
```

其中，`cal` 为对应芯片的内部参考电压校准 ADC 值，`pwr_raw` 为当前测得的 ADC 转换结果。实际使用时应以目标芯片的校准数据定义及参考手册为准。

### 3. STOP 低功耗模式

完成当前周期的任务后，程序暂停 HAL 的 SysTick 时基，进入 STOP 模式等待中断唤醒。唤醒后重新配置系统时钟，再恢复 HAL 时基。

核心流程如下：

```c
HAL_SuspendTick();

HAL_PWR_EnterSTOPMode(
    PWR_LOWPOWERREGULATOR_ON,
    PWR_STOPENTRY_WFI
);

SystemClock_Config();
HAL_ResumeTick();
```

需要注意，STOP 模式唤醒后，系统时钟通常需要重新配置；此外，实际低功耗表现还与外设状态、GPIO 配置、LCD 驱动电路和唤醒源有关。

## 功耗测试

以下数据来自当前硬件的实际测试，供参考。

| 工作状态 | 实测电流 |
| --- | ---: |
| STOP 低功耗模式 | 约 87 μA |
| 唤醒及任务执行阶段 | 约 140 μA |

### 低功耗模式

![STOP 模式电流测试](https://image.lceda.cn/oshwhub/pullImage/686c1cf5b68f4a9b9aeff448f7525c5f.png)

当前 STOP 模式下的整机电流约为 **87 μA**。

初步测试发现，维持 LCD 显示可能占据其中约 70 μA。后续仍可从显示驱动、外围电路、GPIO 状态及休眠前的外设配置等方面进一步排查优化空间。

### 唤醒阶段

![唤醒阶段电流测试](https://image.lceda.cn/oshwhub/pullImage/d89ec00cc3e8427eb038e3ae9005e65c.png)

MCU 从低功耗模式恢复并执行任务时，电流约为 **140 μA**。由于该阶段持续时间较短，仪器显示值可能受到采样时间及测量方式影响，测试截图中的瞬时读数不宜直接作为实际峰值或平均电流。

目前的测试结果仍有进一步优化的空间，后续如有新的测试数据会继续更新。
